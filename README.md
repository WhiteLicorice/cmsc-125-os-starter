# Your operating system's name

This file becomes the specification of your operating system. Replace the title
above with the name of your operating system.

The specification template is in the CMSC 125 "OS Specs" material. Copy the
template into this file, and fill it in as your operating system grows.

`ABOUT.md` documents this starter, its commands, and its tests. Read it before
you begin.

The test badge is red until the selected stage passes. That is the correct state
for a fresh fork.
